# inbox/

项目的临时入口。所有尚未分类的新内容先放这里。

包括：用户上传资料、新需求、临时笔记、截图、网页资料、agent 收集的信息、
待整理文件。

**inbox 是缓冲区，不是永久存储区。**

Agent 应定期执行 Inbox Triage，把内容分类到：

| 内容性质 | 去向 |
|---|---|
| 长期业务领域的问题 | `areas/` |
| 工作输入（参考、调研、原始资料） | `resources/` |
| 已确定要做的任务 | `work/queued/` |
| 可交付成果 | `outputs/` |
| 已被取代的旧内容 | `archive/` |

不要让它长期堆积。当前状态：**空**。
