# outputs/

保存**可以交付、审核或使用的结果**。

```
outputs/
├── reports/      # 审计报告、分析报告
├── designs/      # 设计稿、原型
├── exports/      # 导出文件
├── documents/    # 成文文档
└── releases/     # 发布产物
```

判断标准：如果这个文件可以发给用户、客户、同事、开发团队或运营团队进行审核
或使用，它通常属于 outputs。

## 与 docs/ 的区别

| | `outputs/` | `docs/` |
|---|---|---|
| 性质 | 交付物 | 项目文档 |
| 生命周期 | 交付后即可归档 | 长期维护 |
| 例子 | 给丰怀看的审计报告 | next-wp 架构调研（见 DEC-007） |

## 注意

**不要把临时文件放这里。** 本目录只放成型、可交付的东西。
