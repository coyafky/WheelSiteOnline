# Vossen 轮毂目录 UI 参考审计

日期：2026-10-09

参考页：[Vossen Wheels](https://vossenwheels.com/wheels/)

## 可借鉴的视觉方法

1. 产品区使用大面积白色画布，卡片不靠圆角、描边和阴影分隔，而靠稳定的列宽与纵向留白。
2. 轮毂主图统一放在正方形陈列区中，产品图的视觉面积明显大于文字信息。
3. 型号、系列、尺寸、价格和表面选项全部居中，并通过字号、字重与间距分层。
4. 左侧筛选是轻量文字目录，控件不与产品卡争夺视觉注意力。
5. 系列说明作为编辑型内容进入产品网格，帮助用户理解产品线，而不是只展示无上下文的 SKU。

## 丰怀的适配方式

- 保留 PCD → 直径 → 宽度 → 工艺的生产目录筛选顺序，不改成只有系列筛选。
- 卡片改为无外框白底、正方形图片、居中规格摘要和更大留白。
- 型号级真实 variant 仍是唯一规格来源；不加入价格、库存、载荷或未经批准的车型适配。
- 当前图片来源背景不统一，CSS 只能改善陈列，不能伪装成统一棚拍。图片去背景和统一拍摄规范另立资产任务。

## 禁止复制

- 不下载或复用 Vossen 的轮毂图片、Logo、系列标识、色板、文案与产品数据。
- 不复刻其价格、销售渠道或系列分类；丰怀目录仍是生产记录入口，不伪装成零售商城。
