# resources/

保存**工作输入** —— 不是最终成果。

```
resources/
├── references/      # 参考资料、规范原文
├── research/        # 调研过程与中间结论
├── screenshots/     # 截图、视觉参考
├── datasets/        # 数据表、产品目录
├── documents/       # 文档
├── brand-assets/    # Logo、字体、品牌素材
└── raw/             # 原始未加工材料
```

判断标准：如果这个文件是**为了产出别的文件**而存在，它属于 resources。

## 注意

本项目已有的调研产出（`docs/research/` 下的 `next-wp` 四篇、竞品侦察、
询盘架构方案）**保留在 `docs/` 不动**，因为它们是完整的论述文档，不是中间
材料。参见 `DEC-007`。

resources 用于存放尚未成文的过程材料。
