## 2. 页面实际结构

桌面端没有大型 Hero，导航之后立即进入目录：

1. 左侧筛选栏包含 Series、Size、Price 三类入口。
2. 分类列表具有层级和结果数量，例如 All Wheels、New Release、3-Piece、Hybrid Forged、不同 Forged Series。
3. 右侧采用四列产品网格；首个分组在网格中插入一张系列介绍卡。
4. 产品卡以大尺寸正面轮毂图为主，随后是 New Release 标签、型号、系列/结构、直径、起售价、颜色圆点和表面处理数量。
5. 页面把大量产品连续放在同一目录流中，抓取文本中没有 `Load More` 文案。

抓取到的 HTML 显示筛选入口为 `Filters → Series / Size / Price`；产品卡按型号列出尺寸、起售价和 finish 数量。以上事实以该页面 2026-10-04 的公开版本为准。

## 3. 值得借鉴

- 产品优先：用户一进入页面就看到筛选和第一排产品，不先经过大段品牌叙事。
- 图片优先：统一正视角和留白让不同轮毂易于比较。
- 卡片信息顺序清楚：型号 → 工艺/系列 → 尺寸 → 商业信息 → 表面处理。
- 桌面筛选常驻，分类带数量，当前结果范围容易理解。
- 系列说明和产品网格放在同一浏览上下文，不要求用户先阅读另一个页面。

## 4. 不照搬的部分

- 峰徊没有核准公开价格，所以不使用 Price 筛选或 `Starting at`。
- 峰徊的真实数据按型号/变体组织，不具备 Vossen 的品牌系列体系；`styleName` 还包含第三方商标，不能直接当 Series。
- 现有 531 种中文 finish 原始写法尚未归一化，不能直接生成颜色圆点或表面处理筛选。
- 1073 个候选型号不能一次性渲染到同一 DOM；采用服务端筛选和分页。
- 390px 参考截图出现横向溢出，产品列被视口裁切。峰徊移动端使用单列卡片和可访问筛选抽屉。
- Vossen 的车型、价格、New Release 和颜色数量只属于它自己的数据，不能迁移到峰徊。

### 数据质量门槛

- 原始 PCD 有 34 种写法，13 个有图型号包含明显异常或待解释的复合写法，例如 `4`、`120`、`5-114.3`、`5*112()`、`5*112-5*114.3`、`10*5*112-5*114.3`。
- 表面处理共有 531 种原始文本，存在同义词、简繁/用词和组合工艺差异；需建立英文公开名与颜色族映射。
- `styleName` 包含 TE37、BBS、HRE、Rays、Work 等第三方商标或车型线索；公开前必须移除、改写或取得合法使用依据。
- `vehicleHints` 从 `styleName` 派生，源数据的 `suitableVehicles` 实际为空，不能作为车型适配筛选。

这些问题直接进入 [轮毂目录 Page SPEC](../../PAGE-SPECS/wheel-catalog.md) 的发布与筛选门槛。
