# 2N 首页结构参考与峰徊适配记录

- 日期：2026-10-05
- 参考页面：<https://2nforged.com/>
- 目的：提取首页的信息节奏、视觉层次和交互模型，转换为峰徊四产品线首页方案。
- 边界：只参考结构与行为，不复制 2N 的品牌、文案、图片、视频、Logo、轮毂分类或商业承诺。
- 补充依据：`docs/research/2nforged-reference.md` 中既有 CSS、DOM 和交互审计。

## 1. 当前参考页的有效结构

当前页面从上到下保持四个主要内容段：

1. 全视口深色 Hero：一张汽车主视觉、强标题和单一轮毂定位。
2. 六项能力条：桌面 3×2，用编号、短标题和一句说明快速建立信任。
3. 产品展示：居中标题、三张轮毂视觉和两个目录/画廊入口。
4. 全视口 Gallery 收口：以大字和背景视觉把用户引向图库。

全站还使用透明转实色 Header、滚动显现、轻微视差与固定询盘按钮。结构优点是每个主要视口只回答一个问题，首页没有堆叠长技术说明。

## 2. 不能照搬的内容

| 2N 首页内容 | 峰徊处理 |
|---|---|
| 单一锻造轮毂定位 | 改成轮毂、EV 三电壳体、定制铝制品、自密封轮胎四条平行产品线 |
| Aggressive fitment 等改装语境 | 首页使用采购、工程评估、制造与验证语境 |
| 六项轮毂卖点 | 改成工程、成形、机加工、过程、验证、文件六项制造能力 |
| 三张轮毂产品展示 | 改成四条产品线 2×2 入口，每条线一个独立业务范围 |
| 全屏 Gallery CTA | 改成“一个项目接口、不同制造路线”的工厂证据与交付流程 |
| Factory Direct | 未完成法人和资产关系确认前，使用 `factory-backed`、`manufacturing partner`、`responsible facility` |
| 20–30 天周期 | 不采用；峰徊没有核准的统一交期 |
| 竞品图片和品牌资产 | 禁止进入仓库或公开产物 |

## 3. 峰徊首页采用的结构映射

| 参考结构 | 峰徊视口 | 转换后的问题 |
|---|---|---|
| 全视口 Hero | H01 | 峰徊是谁，能组织什么类型的制造项目 |
| 六项能力条 | H03 | 制造能力是否覆盖工程、成形、加工、过程、验证和文件 |
| 三产品展示 | H02 | 我的需求属于哪一条产品线 |
| Gallery 收口 | H04 | 不同产品线怎样进入负责的制造路线并形成交付证据 |
| 固定询盘入口 | H05 / 全局按钮 | 我现在如何提交型号、图纸或需求 |

H02 放在 H03 前，原因是峰徊首先需要纠正“这是一家轮毂网站”的旧印象。用户先看到四条平行线，再阅读跨产品线的制造能力。

## 4. 可复用的视觉语言

- 深色全视口开场，使用一张获准的制造场景作为主视觉。
- 浅色内容段与深色证据段交替，最后使用现有品牌强调色收口。
- 大写窄行标题、短 Eyebrow、有限正文宽度、明显留白。
- 产品线使用 2×2 大卡；能力使用 3×2 文本单元，两个模块不重复回答同一问题。
- 图片悬停只做轻微缩放和亮度变化，不使用竞品的双图换角资产模式。
- 沿用项目现有 `data-reveal`、`data-reveal-group` 和 `data-parallax-media`，不复制竞品 JS。
- Header 可以继续使用已有的透明到实色滚动状态；固定询盘按钮在移动导航打开时隐藏。

## 5. 峰徊素材建议

| 首页用途 | 候选素材 | 使用条件 |
|---|---|---|
| H01 制造 Hero | WP 114 厂区航拍 | 明示为合作制造基地；图权、主体和关系获批 |
| H02 轮毂 | 一个批准 `WheelModel` 主图 | 工艺、供货、图权和公开名称批准 |
| H02 EV 壳体 | WP 49 或 WP 24 | 只描述可见壳体类别，不由图片推断工艺/性能 |
| H02 定制铝制品 | 2D/3D/Sample 抽象输入图形 | 当前没有可靠通用定制产品图，不用三电图冒充 |
| H02 自密封轮胎 | WP 153 | LOAKE/品牌、图权和供应关系确认后使用 |
| H04 轮毂制造 | WP 61 / 116 | 分别标注铸造场景与旋压设备；不写成所有轮毂固定路线 |
| H04 铝件制造 | WP 78 或 WP 38 | WP 38 仅为批量壳体场景，不称焊接/泄漏检测 |
| H04 轮胎制造 | WP 155 | 标注供应商生产环境；不写峰徊自有产线 |

没有批准视频时，Hero 使用静态图片。将来若提供 8–12 秒工厂循环视频，需要独立图权、主体、地点、流程说明、poster、静音和 reduced-motion 降级，不以视频作为上线前置条件。

## 6. 对当前首页的影响

- `HomeHero` 的轮毂/汽车场景轮播需要替换为单一批准制造视觉或批准视频，不保留竞品式汽车广告感。
- `TrustStrip` 六项现有文案中 `under one roof`、`factory direct`、private label 与部分检测主张需要按证据重写。
- `ProductShowcase` 保留 2×2 结构，但四张卡的内容和图片必须与各产品线 Page SPEC 一致。
- `WheelStripSection` 让首页再次偏向轮毂，应从首页移除；真实轮毂目录留在轮毂入口。
- `DealerCta` 改为统一项目评估入口，主按钮指向 `/request-a-quote`，不承诺固定报价或交期。
- 首页不增加 Gallery，避免建立一个当前素材和授权都不完整的空入口。
