# 旋压轮毂页面资料与数据核验

- 日期：2026-10-05
- 目的：为 `/products/wheels/flow-formed` Page SPEC 建立可追溯的工艺、产品数据和媒体边界。
- 原则：只记录资料与数据能够支持的事实，不把设备照片、目录字段或行业常识扩写成产品性能保证。

## 1. 输入资料

### 1.1 航鹏轮毂资料

`3家公司的PPT资料/航鹏画册_A版/A轮毂_产品手册核心介绍.md` 提供以下信息：

- 公司资料列出旋压成型加工能力。
- 制造章节把重力铸造、低压铸造和旋压成型分别描述。
- 原文称旋压结合锻、挤压、拉伸等成形特点，并提出致密度、力学性能和轻量化收益。
- 配有一张旋压成型设备照片。

其中“提高性能”“轻量化”等是供应商资料中的一般工艺主张。没有具体型号、对照件、重量、材料、工艺参数和试验报告时，页面不把这些内容写成所有旋压型号的结果。

### 1.2 峰徊综合资料

`3家公司的PPT资料/峰徊科技_A版/A科技_产品综合介绍.md` 将轮毂范围概括为铸造、旋压与锻造，并描述材料/模具、铸造/旋压、热处理、CNC、涂装和检测等制造环节。

该顺序只能作为供应商资料中的能力范围。重力铸造、低压铸造、旋压和锻造不是每个轮毂必经的连续流水线，具体路线必须由型号数据和项目文件确认。

## 2. 真实目录审计

数据来源：

- `assets/wheel-data/WHEEL-CATALOG-ALL.json`
- 生成结果 `src/content/wheel-catalogue.ts`
- 图片目录 `public/images/wheels/`

当前生成结果：

| 目录状态 | 型号数 | 说明 |
|---|---:|---|
| 工艺记录为 `旋压` | 350 | 其中 320 个由生成器匹配到图片 |
| 工艺记录为 `低压+旋压` | 20 | 其中 10 个由生成器匹配到图片 |
| 两类合计 | 370 | 330 个有图技术候选，40 个无图不上架 |
| 有图候选中的实际变体 | 762 | 每条变体保留自身尺寸、PCD、ET、中心孔和 finish |

这些数字是内部数据审计结果，不是公开可售数量：

1. `hasImage=true` 只证明生成器匹配到本地图片。
2. 图权、供货、英文工艺翻译、规格异常和发布状态尚未形成完整批准覆盖层。
3. 目录中的第三方款式名不能公开沿用。
4. `旋压` 只说明源数据记录了旋压，不能反推其毛坯一定是低压铸造。
5. 只有明确记录为 `低压+旋压` 的型号才能显示该组合路线。

## 4. 页面可发布的事实

- 真实目录可按记录工艺筛选 `旋压` 与 `低压+旋压`。
- 对适用轮毂项目，旋压用于轮辋区域的受控成形；具体毛坯路线、材料、后续加工和验证按型号或项目确认。
- 旋压与整体锻造是不同路线，页面不能把两个词互换。
- 型号规格必须来自同一条真实 `WheelVariant`，不能由尺寸、PCD、ET、中心孔和 finish 自由拼接。
- 产品图、工艺记录和供货状态全部批准后，型号才进入公开列表和 sitemap。

## 5. 页面不可发布的主张

- 通用减重百分比、强度提升比例、材料密度或寿命提升。
- “比铸造更强”“等同锻造”“所有旋压轮毂更轻”等绝对比较。
- 没有记录时推断毛坯来自低压铸造。
- 用设备照片证明某个公开型号已经完成该工序或通过测试。
- 直接显示内部 330 个有图候选或 762 条变体为“可售库存”。
- 车型适配、载荷、刹车间隙、目标市场合规、库存、价格和交期保证。

## 6. 对 Page SPEC 的影响

- 页面定位为“工艺解释 + 已批准旋压型号集合”，不是泛化性能宣传页。
- Hero 产品必须来自批准覆盖层；没有批准型号时使用能力说明并保持 `noindex,follow`，不放假产品。
- 工艺区绑定 WP 116，产品区复用真实目录组件和统一详情页。
- 列表锁定两个允许值：`旋压`、`低压+旋压`；前台分别显示 `Flow formed` 与 `Low-pressure cast + flow formed`。
- 询盘必须携带完整变体生产代码和服务端规格快照。
