# 车辆场景背景图生成记录

日期：2026-10-09

## 使用边界

- 三张图均由 OpenAI 图像生成工具为本项目生成，不是客户案例、实拍工厂资料或车型适配证明。
- 车型仅采用“高性能 GT、电动跨界车、家庭 SUV”这类市场分段语言，不对应任何真实品牌或精确车型。
- 生成提示明确排除 Logo、车标、车牌、可读文字、赛事贴纸、水印和可识别的品牌造型。
- 页面中按装饰图处理：空替代文本、`aria-hidden`、深色遮罩；不进入产品证据链。
- 原始生成 PNG 保留在 Codex 生成目录；站点只使用压缩后的 WebP。

## 生成提示摘要

三次生成均要求：16:9、写实商业汽车摄影、左侧约一半留低细节暗部、车辆位于右侧、石墨/钢蓝/暖琥珀色调，并明确排除真实品牌、精确车型、商标、车牌、文字和水印。

## 页面表述约束

这些图片只回答“该产品可能出现在哪类使用语境中”，不能据此表述某车型已经适配、某客户已经采购、某项测试已经通过，或图片中的车辆使用了丰怀产品。
