## 结论

语言切换不再使用外框和独立圆角底色；当前语言只用品牌色表示。桌面询盘入口取消胶囊
描边，使用品牌色文字和方向箭头；移动菜单保留更强的品牌色底，以维持触控目标与转化
层级。四种状态没有横向溢出，英文与中文导航均保持单行。

截图中的红色 `1 Issue` 为 Next.js 开发模式提示，不属于生产页面元素。
