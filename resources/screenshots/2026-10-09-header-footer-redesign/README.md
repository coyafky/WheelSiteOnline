# 页头与页脚视觉复核

- 日期：2026-10-09
- 参考：https://2nforged.com/#top
- 边界：只研究版式、层级、留白、透明导航、字标尺度与深色页脚结构；未复制对方图片、
  Logo、文案、字体文件或代码。

## 采用的结构语言

- 首屏透明页头，滚动后切成白色实体导航；
- 横向导航使用细下划线表达当前项，不再把每项做成胶囊；
- 以自有 `FH` 方形字标和 `Fenghuai Manufacturing` 形成公司级锁定；
- 页脚以大号行动标题开场，再进入编号导航和版权/语言区；
- 橙色只用于激活、编号和关键行动，不大面积铺色。

## 丰怀自己的实现

- 导航结构按四条真实产品线组织，不沿用竞品产品分类；
- 所有文字来自丰怀内容模块或中英字典；
- 语言切换连接英文根 URL 与中文 `/zh/*`；
- 悬浮询盘按钮进入页脚时隐藏，避免遮挡链接。
