## ★ 图片命名规则 —— 文件名即产品代码

```
<尺寸前缀>-<产品代码>[-<序号>].webp
```

| 例子 | 拆解 |
|---|---|
| `15-1081x.webp` | 15寸 ｜ 代码 `1081X` |
| `15-1081x-2.webp` | 同一代码的第 2 张 |
| `17-3-2507065.webp` | 分册前缀 ｜ 代码 `2507065` |
| `off-road-rh10018-3.webp` | 越野款 ｜ 代码 `rh10018` |

**提取方法**：剥掉尺寸前缀（`15-` / `17-3-` / `off-road-` / `hp-`）与末尾
序号（`-2` / `-3`…），剩下的即产品代码，**小写归一化后对应 `models[].model`**。

实测匹配率 **2185 / 2757 = 79.3%**。

⚠️ **未匹配 572 张（21%）**，主要是：
- 越野款（`off-` 前缀 123 张）+ HP 款（`hp-` 31 张）→ **`models[]` 里无对应记录**
- 分册前缀类（`17-2-*` 等）

**核清之前，这 572 张只可用于画廊展示，不得绑定 SKU。**

**不要重命名图片文件** —— 文件名是产品代码，改名即断链。
