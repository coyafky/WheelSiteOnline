# 深圳峰徊独立站

Next.js 前端与 Headless WordPress 内容后端的网站项目。业务范围、稳定约束和技术目标见 [`PROJECT.md`](PROJECT.md)；当前阶段与阻断以 [`STATUS.md`](STATUS.md) 为准。

## 开始开发

要求：使用仓库 `package.json` 声明的 Node.js 与 npm 版本。

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run lint
npm run typecheck
npm run build
npm run check
```

代码任务开始前先查看 [`CLAUDE.md`](CLAUDE.md)（Claude Code）或 [`AGENTS.md`](AGENTS.md)（项目规则），然后根据 [`DOCUMENTATION.md`](DOCUMENTATION.md) 只读相关规格、架构或任务。工作流步骤与 Skills 对照见 [`SKILLS/README.md`](SKILLS/README.md)。
