# WordPress 轮毂与 Insights 无代码运营闭环

- **状态**：已完成
- **创建日期**：2026-10-09
- **来源规格**：用户 2026-10-09 要求；DEC-069

## 问题

轮毂后台目前只能编辑发布决定，规格与图片仍依赖仓库生成物；Insights 虽有内容类型，
但正文使用原始 JSON 文本框、没有文章图片，现有六篇内容也尚未迁移和接管。运营人员
无法只在 WordPress 中完成新增、修改、撤回与图片更新。

## 目标结果

运营人员可在 WordPress 中维护型号、多个真实规格、主图/图库和 Insights 结构化正文；
Next.js 通过稳定契约读取，CMS 故障时使用最后有效兜底，保存/撤回/删除自动失效缓存。

## 纵向切片与验收标准

### WPC-01 轮毂后台录入与公开契约

- [x] 后台可编辑型号、SKU、直径、宽度、PCD、ET、中心孔、表面处理和规格顺序。
- [x] 后台可从媒体库选择主图与图库，并保持无图不上架。
- [x] `/fh/v1/wheels` 只输出完整批准字段，不泄露内部事实和备注。
- [x] 草稿、撤回、缺图、缺规格或任一门槛未通过时 fail-closed。

### WPC-02 Next.js live 读取与兜底

- [x] 四个既有 `@/lib/wheels` 公共接口与页面组件类型不变。
- [x] live 模式读取 WordPress 权威集合；网络/契约失败使用最后有效静态集合。
- [x] WordPress 权威空集合保持为空，不回退旧产品。
- [x] 目录、详情、筛选、sitemap 与询盘复核继续读取同一集合。

### WPC-03 发布事件自动失效

- [x] 轮毂和 Insights 保存、撤回、回收站与删除会发送 HMAC-SHA256 签名 webhook。
- [x] Next.js 按内容类型失效正确 tag 与路径，错误签名返回 401。

### WPC-04 Insights 运营编辑与迁移

- [x] 列表短版和正文分段使用可增删排序的结构化编辑器，不要求运营手写 JSON。
- [x] 每篇文章可选择特色图片，前台列表和文章首屏使用同一批准媒体。
- [x] 现有六篇本地文章幂等迁入 WordPress，核验成功后打开权威接管。

### WPC-05 FH-002 全生命周期验收

- [x] 临时 FH-002 草稿不可见；批准后进入目录、筛选、详情与 sitemap。
- [x] 修改规格后前台刷新；撤回后四个消费者同时消失。
- [x] 测试记录与测试媒体清理，不把虚构规格留作正式产品。
- [x] CMS、单元测试、lint、typecheck、build、浏览器关键路径全部通过。
