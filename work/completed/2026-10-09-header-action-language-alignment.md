# 页头询盘入口与语言切换视觉统一

## 问题

桌面页头的语言切换和询盘入口各自使用完整胶囊描边，与中间文字导航形成三套视觉语法；
两个控件的边界感强于主导航，抢夺注意力。

## 处理

- [x] 语言切换改为同一基线上的 `EN / 中文` 文字状态，以品牌色标记当前语言。
- [x] 桌面询盘入口取消胶囊描边，改为品牌色文字与方向箭头。
- [x] 移动菜单同步简化；询盘入口用品牌色背景强调，不再叠加描边与圆角胶囊。
- [x] 桌面透明态、桌面滚动态、中文桌面态和手机菜单截图验收。
- [x] 工程门禁与 23 项浏览器 E2E 通过后归档。

## 完成结果

语言切换与询盘入口已回到同一导航基线。桌面端取消两个胶囊描边，用品牌色状态和箭头
区分主次；移动菜单以文字语言状态配合品牌色矩形询盘入口。英文/中文、透明/滚动态与
390px 菜单均通过截图验收。
