# Knocket Web Widget 受控试点

- 状态：待执行
- 创建日期：2026-10-10
- 前置评估：`outputs/reports/19-knocket-chat-integration-feasibility-2026-10-10.md`

## 用户结果

在不改变正式询盘主链路的前提下，访客可以在指定页面向峰徊发起快速聊天；聊天不可用时，正式询盘、产品页和移动端仍正常工作。

## 范围

- 使用峰徊自己的 Knocket identifier，不使用模板页公开 identifier；
- 在受控页面加载一次异步 Web Widget；
- 配置品牌色、英文欢迎语、离线语和正式询盘入口；
- 记录实际第三方网络域名，建立最小 CSP allowlist；
- 验收桌面/390px 移动端、键盘、关闭、脚本失败、性能和控制台；
- 验证访客消息、Telegram/Email 通知、人工回复和会话回访；
- 在隐私政策中补充第三方聊天说明前，不收集不必要的敏感资料。

## 非范围

- 不替换 `/api/inquiries`、WordPress 询盘 CPT、发件箱或隐私版本校验；
- 不把聊天当作报价、产品规格、车型适配或认证的事实来源；
- 不启用未经审核的 AI Agent、自动报价、自动车型推荐或内部知识库；
- 不全站无条件显示，不在 `/request-a-quote`、`/contact`、`/thank-you` 和隐私页面与正式流程竞争；
- 不提交、推送或部署，除非另有明确授权。

## 阻塞于

- 供应商数据处理、服务区域、删除/导出、分包商和服务连续性说明；
- 业务/法务确认第三方聊天隐私文本和跨境处理口径；
- 真实账户生成的 SDK 网络依赖与 CSP allowlist；
- 销售确定 Telegram/Email 接收责任人、备份和交接方案。

## 验收标准

- 正式询盘仍写入原有契约，Knocket 消息不会被误报为询盘成功；
- Knocket 脚本失败或被 CSP 拒绝时，页面无破图、无横向溢出、无阻塞式错误；
- 产品详情页保留既有直接询盘和型号/变体上下文；
- 移动端聊天气泡不遮挡浮动询价、主按钮、Cookie/隐私提示或键盘焦点；
- `npm run lint`、`npm run typecheck`、`npm run build`、相关 Playwright 与第三方性能回归通过；
- 业务完成真实访客消息—通知—回复—回访闭环演练后，再决定是否扩展页面范围。
