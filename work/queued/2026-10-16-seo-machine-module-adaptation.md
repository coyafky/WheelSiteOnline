## 目标

将 SEO Machine 中适合本项目的研究 brief、页面 SEO 检查、内容审校、内链建议和后续性能复盘能力，逐步改造成受项目事实、索引与 CMS 发布门槛约束的编辑工作流。

## 范围

- 首轮只读审计 metadata、canonical、语言路径、robots、sitemap 和公开内容结构。
- 后续挑选一个证据齐全、页面 owner 已批准的主题完成 brief、草稿、事实来源表、SEO 检查和内链建议。
- 经过人工评估后，再决定是否沉淀项目专用 Skill、接入只读 GSC/GA4 数据或实现 WordPress 草稿辅助。

## 不在范围

- 不整仓克隆或将 SEO Machine 加为网站运行时依赖。
- 不自动付费、接入真实分析账号、调用收费 API 或发布正式内容。
- 不自动改变索引资格、sitemap、翻译状态或 WordPress 审核状态。
- 不生成无事实依据的产品/技术/供应链主张，不按固定字数或评分追求所谓排名。

## 验收标准

- 输出的审计结论能区分代码证据、需要业务确认的事项和当前无数据的事项。
- 首个内容样稿的事实可追溯、语言/页面归属正确、内链只指向获批页面，并经人工审核。
- 对自动化或依赖的后续投资有人工对照证据；若收益不足，保留轻量手动流程并记录结论。
- 任何 CMS 写入能力先以仅草稿、可审计、人工发布为约束，经负责人单独批准后才开始实现。

## 风险

- 自动化生成可能把竞品、模板或无来源假设变成公开事实；必须保留项目的证据纪律和页面发布门槛。
- SEO 建议分数不是 Google 排名预测，单轮 SERP 与历史主题地图也不是搜索量或流量基线。
