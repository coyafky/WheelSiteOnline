# 轮毂目录图片规范化与重制

## Spec-Driven 元数据

- **Phase**：3
- **Milestone**：待创建/映射
- **GitHub Issue**：[#8](https://github.com/coyafky/WheelSiteOnline/issues/8)
- **Delivery Batch**：图片衍生与人工复核批次
- **依赖**：首发型号集合、图权、人工复核和公开媒体接缝
- **S.U.P.E.R 关注**：Single Purpose（只处理衍生图）；Environment-Agnostic（保留可复现处理记录）；Replaceable Parts（原始 assets 只读，衍生层可替换）
- **验证命令**：断图、LCP、移动裁切、视觉回归、来源映射检查、`git diff --check`
- **漂移规则**：任何生成式改图或产品事实变化立即停止并进入 Deep Discuss

## 背景

目录 UI 已改为白底无框陈列，但现有批准图片来自不同拍摄环境：背景颜色、轮毂占比、
角度、阴影、裁切和清晰度不一致。CSS 可以统一容器，不能把来源照片变成一致的商业棚拍。

## 目标

在不修改 `assets/` 原始资料、不虚构产品细节的前提下，为首发批准型号建立可复现的图片
处理与人工复核流程，输出统一的公开 WebP 衍生图。

## 验收标准

- 为首发集合定义正面角度、轮毂占画布比例、背景、阴影、边距、分辨率与 WebP 质量规范；
- 自动处理只做裁切、背景清理、色温/曝光归一与压缩，不生成或改写轮辐、孔位、Logo、
  表面处理和其他产品事实；
- 每张衍生图都保留来源映射、处理记录与人工“未改变产品几何”复核；
- 不合格源图进入重拍/补图清单，不用生成式图像冒充真实 SKU；
- 更新 WordPress 媒体与公开快照后，重新跑断图、LCP、移动裁切和视觉回归测试。
