# 全站 Astryx Neutral 暖白界面规格

- 日期：2026-10-11
- 状态：全站主题与 P5 跨模板本地回归已完成；商用发布仍受内容／法务／运维门槛约束。证据见 `outputs/reports/33-astryx-p5-final-commercial-seo-handoff-2026-10-11.md`。
- 适用：全部公开页面模板及英文、中文、西班牙语、泰语路由；不改变原有逐页内容、证据和 SEO 门槛。
- 依据：用户指定 Neutral 与白色暖色调；系统边界见 `ARCHITECTURE.md` §3.1。

## 问题与目标

全站已挂载 Neutral 根主题、暖白品牌令牌与静态主题 CSS，关键交互逐切片接入 Astryx 原语。访客应看到暖白底、清晰深色文字与克制的铜色行动点；跨页焦点、错误、提交和完成状态一致，同时保留 WordPress 已批准内容与真实轮毂规格。未直接导入 Astryx 的业务区块仍共享主题，而不是未迁移的黑灰橙孤岛。

## 全站视觉语法

| 语义层 | 目标 | 实现来源 |
|---|---|---|
| 页面底 | 近白、微暖；长文和产品照片保持清晰 | `globals.css` 的 `--fh-background`，映射 Astryx 背景令牌 |
| 卡片/弹窗 | 白色表面，暖灰细边；以内容层级而非大阴影分组 | Astryx Card/Dialog 及项目卡片共用语义令牌 |
| 次级段 | 低饱和暖灰，和白底交替 | `--fh-soft` |
| 正文/次级文字 | 暖炭黑与暖灰；数据和规格可快速扫描 | `--fh-ink`、`--fh-steel` |
| 行动色 | 克制铜棕；用于主要行动、焦点和当前选中，不铺满普通内容段 | `--fh-forge` 及 Astryx accent 令牌 |
| 分割线 | 暖灰细线，真实工艺流程可用连续线表示顺序 | `--fh-muted` |

字形分工：Neutral 的正文采用 Figtree，短标题仍用 Barlow Condensed，型号与生产代码使用等宽数字排版。标题不把普通按钮和法律正文一起强制大写。页面以轻表面、留白和细规则建立工业精度感，不使用无事实含义的 KPI 数字或刻度。

## 主题与组件规则

1. 根布局在服务端输出浅色模式；客户端 Provider 统一提供 Astryx Theme、Next 链接适配、四语言和 Toast。关键样式由静态主题 CSS 首屏加载；不得依赖水合后的主题注入才使文字可见。
2. 页面使用项目语义令牌，不在组件内写颜色字面量。Astryx 原语与项目组件应使用相同背景、文字、边框、圆角、焦点和动效节奏。
3. 共享交互的选择顺序：现有 Astryx 组件 → 经验证的薄适配器 → 保留原生 HTML。采用与否由语义、服务端渲染和业务行为决定，不以组件覆盖率衡量。
4. 深色图底可用于真实照片内部，但首屏文案区和导航采用暖白基调。任何真实照片上叠文字都要有独立的对比度验收；没有图片时保留 `hasRender` 兜底。
5. 交互必须有 hover、focus-visible、disabled、loading、success 和 error 状态；移动端不靠 hover 才能操作。尊重 reduced motion。

## 页面族映射

| 页面族 | Astryx 或共享外壳 | 继续由项目组件负责 | 特别验收 |
|---|---|---|---|
| Header、Footer、语言与询盘入口 | Theme、Toast 等适用原语 | 路由、导航层级、菜单触发与 Next Link；无全站悬浮询盘按钮 | 浅色 Header 在所有首屏可见；桌面/移动菜单、页脚与产品页保留询盘路径 |
| 首页、About、Capabilities、产品中心 | 面包屑、提示、通用行动控件 | 品牌 Hero、真实媒体、主体关系、能力矩阵 | 四线平等；证据归属不变；照片失败可见 |
| 轮毂目录与旋压入口 | Field、Banner、EmptyState 等已验证原语 | 原生多值 GET、普通链接分页、真实产品卡 | 同一 variant 交集、URL 可复制、无 JS、发布门槛 |
| 轮毂详情与锻造项目 | Dialog、NumberInput、反馈控件 | 真实变体、finish 与工程边界 | 直接询盘和总清单隔离；数量无业务上限 |
| EV、定制铝件、轮胎 | 通用行动、提示和字段控件 | 能力说明、证据图、询盘输入 | 不伪造库存 SKU、认证或性能承诺 |
| 项目询盘与感谢页 | Astryx 表单、Dialog、Banner、Toast | Zod、API、WordPress/MySQL 与 Outbox | 数据库落库才成功；失败保留输入与清单 |
| Insights、Fitment、Tools、法律 | Outline、NumberInput 等适用控件 | 服务端正文、原生锚点、计算公式、未验证适配边界 | 索引/语言审批、无 JS 正文、键盘导航 |

## 每个切片的完成条件

- 1440×900、768×1024、390×844、320×568 代表视口无文字遮挡和页面级横向溢出；截图确认暖白主题和重点控件状态。
- 检查键盘焦点、可访问名称、基础 WCAG A/AA、reduced motion、控制台错误与失败资源。
- WordPress mock 与已批准 live 内容均通过稳定视图契约；草稿、撤回、无图轮毂不会因组件迁移公开。
- 轮毂 GET URL、分页、语言 URL、直接/清单询盘、落库成功语义保持现有回归。
- lint、typecheck、build 与相关 Playwright 完成；未通过的页面族在任务和交接中标明，不能写作已完成。
