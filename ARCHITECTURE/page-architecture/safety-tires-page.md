## 1. 这页的定位：**难点不在于写什么，而在于「我们是谁」**

读完语料库，本页的根本问题只有一个：

> **峰徊在安全轮胎这件事上，是「品牌方」还是「渠道方 / 合作方」？**

**这个问题决定了整个页面的写法**：

| 若峰徊是… | 页面写法 | 主语 |
|---|---|---|
| **品牌方**（洛克是峰徊的品牌） | 可以完整讲技术、质保、渠道 | **「我们的安全轮胎」** |
| **合作方 / 渠道方**（洛克是他人品牌） | 只能讲「我们提供这个品类」，技术描述须归属标注 | **「我们提供的安全轮胎」** |
| **集团内关系**（洛克与峰徊同属一个集团） | 可讲，但须明示关系 | **「同集团品牌洛克」** |

**⚠️ 语料库现状**：多处标注「洛克PDF P16/23：集团国家级高新技术企业」「洛克集团生态」
→ **指向「同集团」的可能性较大，但语料库同时明确写着「两者归属未定」。**
**→ 这是本页的第一个、也是最大的待确认项（见 §6 #1）。**

## 3. ⚠️ 与「独立站」语境的额外风险

**这是全站唯一一条「B2C 属性」的产品线**，与其余三条（B2B 铝制件）性质不同。

| | 轮毂 / 三电 / 铝制品 | **安全轮胎** |
|---|---|---|
| 买家 | 经销商、整车厂、采购 | **可能是终端车主 / 渠道商** |
| 宣传约束 | 商业表述 | **广告法 / 产品责任 / 认证声明** |
| 认证要求 | 客户自审 | **ECE / DOT / CCC 等强制或准强制** |

**⚠️ 由此的额外纪律**：

1. **性能数字必须可追溯** —— 390 耐磨值、60–67 dB(A)、−40~+178 °C
   这些数字**上了官网就是对世界的承诺**，必须有测试报告支撑。
2. **不得使用「扎不破」** —— 「防扎」「扎不破」属**绝对化用语风险区**
   （峰徊自有口径用的是「自密封」「穿刺通道闭合」，**这是更稳妥的表达**）。
3. **认证必须写清范围** —— 峰徊自有口径是
   **「ECE、DOT 等资料按适用型号和目的国确认」** ← **照抄这句，不承诺具体型号**。
4. **不得用「龙头企业」「第一」** 等表述（洛克口径除外，且即便洛克也要授权）。
