## 1. ⚠️ 一个必须先讲清的结构问题：本页的受众不是「经销商」

**`README.md` §2.6 写这页给「整车厂 / Tier1」看。** 这句话决定了本页与全站其他页的**根本差别**：

| | 轮毂线各页 | 本页 |
|---|---|---|
| 访客 | 海外经销商 / 改装店 | **整车厂 / Tier1 采购与工程师** |
| 决策依据 | 外观 + 规格 + 起订量 | **质量体系 + 检测能力 + 保密意愿** |
| 采购节奏 | 单笔、零售规模 | **项目制、年框、多轮打样** |
| 关系性质 | 供货 | **共同开发（co-development）** |
| 主导语言 | 营销 | **工程** |

**⚠️ 由此得到本页的第一条纪律**：
**B2B 形象话术（「实力见证品质」「源头工厂」）在本页无效，甚至会扣分。**
整车厂采购看的是**体系、公差、检测手段、保密流程**。
**本页是全站唯一一页「越像工程文档越好」的页面。**

**⚠️ 第二条纪律**：本页的 CTA **不是「获取报价」，是「提交图纸/需求进入工程评估」**。
报价这个词在三电线是**过早**的 —— 客户此时还不知道我们能不能接。
