## 0. 为什么这一页值得单独做架构

因为**它是全站唯一一页在讲「你能得到什么」而不是「我们多厉害」**。

| 页面 | 主语 | 结果 |
|---|---|---|
| 产品页（monoblock 等） | **我们**（我们的工艺、我们的做法） | 说服力靠**事实** |
| **经销商页** | **你**（你的成本、你的客户、你的风险） | 说服力靠**共情** |

**竞品这一页 14 段里，有 11 段的主语是经销商。** 这是它的核心技巧。

**⚠️ 而且它开头就认了一个对我们也有用的道理**：

> *"This is not the old wheel business where you buy stock first and hope the right customer walks in."*

**它在攻击「囤货模式」这个行业默认玩法** —— 而我们**恰好也是做定制的**（1018 型号按需生产）。
**这个主张我们能直接用，而且是真话。**

## 2. ★ 竞品的三个「可借的骨架」

### 2.1 骨架一：三个数字的信任带（第 0 段下方）

```
MOQ from 1 set / 4 pcs
VIN + target wheel size is enough to start
20-30 day production after final approval
Real production checkpoints before shipment
```

**四条极短的要点，全都在降低门槛。**
注意它**每一条都在减负**（起订量小 / 输入少 / 交期明确 / 可追溯），**没有一条在夸自己。**

**⚠️ 我们能不能用这四条？**

| 竞品要点 | 我们能写吗 |
|---|---|
| MOQ from 1 set / 4 pcs | ⚠️ **需丰怀确认**（语料含「MOQ」词但无具体值） |
| VIN + 目标尺寸就够 | ⚠️ 需确认（VIN 是海外做法，国内常用车型+年份） |
| 20-30 天生产 | ⚠️ **需丰怀确认** |
| 生产节点可追溯 | ⚠️ 需确认能否做到 |

**→ 四条都要丰怀确认。未确认前不能写（DEC-004）。**

### 2.2 骨架二：六个能力卡（第 4 段）

| 竞品的六卡 | 结构 |
|---|---|
| Presold ordering | **Order after the customer is real** + 说明 |
| Reference to production | **Turn a look into a buildable order** + 说明 |
| Production line | **Work with the people building the set** + 说明 |
| Dealer branding | **Logo and caps can start early** + 说明 |
| Repeat orders | **Keep what worked** + 说明 |
| Order visibility | **Follow the order as it moves** + 说明 |

**格式统一**：小标签 + **加粗一句话** + 一段说明。**这个卡片格式我们要照抄。**

### 2.3 骨架三：六步下单流程（第 6 段）

```
01 客户有真实项目        → 收集 VIN/尺寸/风格/表面/数量/发运地
02 2N 评审并报价          → 评审后报实际项目价
03 确认订单               → 形式发票 + 定金
04 ★ 开料前批准           → 在切金属前确认全部细节
05 生产 + 可见的进展      → 20-30 天 + 节点照片/视频
06 尾款、发运与跟踪       → 国际运单号
```

**★ 第 04 步「Approve before metal is cut」是这一页最专业的一步。**
**「在切金属之前确认」** —— 这句话同时做到三件事：
1. 说清风险控制点（改起来便宜 vs 贵）
2. 建立专业感（我们知道哪里最贵）
3. 保护双方（白纸黑字确认过）

**我们必须学这一步。**

## 3. ★ 我们该怎么改（关键差异）

### 3.1 竞品的主张 vs 我们的（根本差别）

| | 竞品 | 丰怀 |
|---|---|---|
| 模型 | **完全定制**（客户给 VIN，我们做） | **目录车型 + 定制** |
| 客户要说 | VIN + 目标尺寸 + 风格 | **型号 + 规格**（我们有 1018 个） |
| 难度 | 客户要描述，**我们猜** | **客户可选，我们查**（有真实数据） |
| 起订 | 1 set / 4 pcs | ⚠️ 待确认 |

**→ 我们的经销商页可以比竞品更好卖，因为我们少了一层「沟通成本」。**

竞品要客户说「什么车、多大、什么样子」→ 它再去做。
**我们可以说：「目录里 1018 个型号，3485 个配置，你直接选。」**

### 3.2 ★ 我们的核心主张（替换竞品的）

| 竞品主张 | 我们的对应主张 |
|---|---|
| 不囤货，客户先来 | ✅ **同样适用**（我们也是按需生产） |
| VIN + 尺寸就够开工 | ⚠️ 改成 → **「目录里就能选，不用等人翻译你的需求」** |
| 1 set 起订 | ⚠️ **待丰怀确认** |
| 20-30 天 | ⚠️ **待确认** |

**→ 我们可以主张「规格透明」这个竞品没有的东西。**

竞品页里客户要问「这个能不能装」，我们要**能当场答**。

### 3.3 我们能引用的真实数字（实测）

| 数据 | 值 | 可用性 |
|---|---|---|
| 型号总数 | **1018**（有图上架） | ✅ 可写 |
| 可下单配置 | **3485 个 variant** | ✅ 可写 |
| 尺寸范围 | **15–20 寸** + HP + 越野款 | ✅ 可写 |
| 表面处理 | **679 个去重值** | ⚠️ 写「数十种」更稳，679 里有近似重复 |
| 工艺 | 旋压 350 / 低压 142 | ⚠️ 覆盖 38%，**不能写成「全部」** |

**⚠️ 竞品写的是 "16-26 inch available"（范围）—— 那是它的**能力声明**。
我们写的是「**目录里有 15–20 寸的 1018 个型号**」—— 这是**事实陈述**。**
**摆事实比给范围强。**

## 5. 逐段内容设计

### ① 核心主张（≤90 字，对齐竞品 92 字）

**竞品范本**：
> Sell custom forged wheels without stocking them first.
> This is not the old wheel business where you buy stock first and hope the right customer walks in.
> Your customer comes first. Once they are ready to order, send us the vehicle, wheel size, style and finish.

**我们的（待丰怀确认后可写）**：
> 卖定制轮毂，不用先囤货。
> 而且不必从零向供应商描述你要什么 —— 目录里有 1018 个型号、3485 个配置，**你直接选规格**。

**⚠️ 三种 CTA（对齐竞品）**：
- 主 CTA → 联系/询盘
- 次 CTA → **WhatsApp 直聊**（竞品用了，B2B 外贸习惯）
- 竞品的 WhatsApp 链接**预填了一整套字段**（VIN/尺寸/风格/表面/数量/发运地）——
  **这个做法很好，我们要学**：点 WhatsApp 时模板已带好要问的信息。

### ② 信任带（四条，全部用真实数字）

**⚠️ 只能写实测数据，缺的留占位**

```
1018 个在册型号          ← ✅ 实测
3485 个可下单配置        ← ✅ 实测
15–20 寸 + HP / 越野款   ← ✅ 实测
数十种表面处理           ← ✅ 实测（679 个去重值）
```

**⚠️ 竞品这四条全是「减负」**（起订小/输入少/交期明/可追溯）。
**我们的是「给选择」** —— 因为我们有数据。
**两种都成立，但不要混着写。**

### ③ 对号入座（T2 段型）

**竞品**：*"If you've only sold stock wheels before, start here."*

**我们的（两个入口更好）**：
- **A：你只卖过现货轮毂** → 先看这里
- **B：你已有定制供应商，想找第二备份源** → 看流程与可追溯

**为什么加 B**：丰怀是制造商，**「第二供应源」是真实且常见的经销商需求**，
竞品没覆盖。

### ④ 四大风险（T2 段型）

**竞品四条**（这是它的精华）：

| 风险 | 竞品的写法 |
|---|---|
| **Capital stuck in stock** | 囤货把店变成仓库 |
| **Promising a date you cannot control** | 客户会问交期，**别在第一条消息就报** |
| **The dispute that lands on your desk** | 客户第一个电话打给你 |
| **The supplier becomes a black box** | 最怕付了定金然后没消息 |

**★ 第 2 条「别在第一条消息就报价交期」是极高明的销售建议** ——
它不是推销自己，是**教经销商做事**。**教客户做事的供应商，看起来更像专家。**

**我们能直接用这四条吗？**
- ①②③ ✅ **完全通用**（任何定制供应链都有）
- ④ ✅ 通用，但我们**要说自己不是黑箱**（用 ⑧ 的可追溯点证明）

**⚠️ 但必须写清我们能提供什么**，不能只列风险不给答案。

### ⑤ 六个能力卡（格式照抄竞品）

| 我们的六卡 | 内容 |
|---|---|
| **按需下单** | 客户先有需求，再下单 |
| **从参考到生产** | 图/型号 → 可生产订单 |
| **★ 规格透明** | **直接查规格，不用来回猜** ← 竞品没有 |
| **贴牌支持** | Logo / 中心盖 |
| **复购复用** | 上次成交的配置存下来 |
| **订单可见** | 生产节点可跟踪 |

**★ 第三张卡是我们的独有优势。** 竞品的六卡里没有这一条 ——
因为它没有规格数据（它的单品页一个数字都没有）。

### ⑥ ★ 目录优势（竞品完全没有的一段）

**这是我们相对竞品的核心差异，必须单独成段。**

内容：
```
1018 个在册型号 · 3485 个可下单配置
15–20 寸 + HP / 越野款
按尺寸 / PCD / 工艺 / 表面处理筛选
每个配置带真实 PCD / ET / CB
```

**配一张目录截图或筛选器示意**（视觉证据）。

**⚠️ 三条纪律**：
1. **不写工艺覆盖为 100%** —— 只有 38% 有标注
2. **不写「全部适配某车型」** —— `suitableVehicles` 全空
3. 数字必须与站点实际一致（若上架型号数变了，这段要改）

### ⑦ 六步流程（学竞品的「开料前批准」）

```
01 你的客户有真实项目   → 车型/尺寸/风格/表面/数量/发运地
02 我们评审并报价       → 按实际项目报价
03 确认订单             → 形式发票 + 定金
04 ★ 开料前批准         → 切金属前确认全部细节
05 生产                 → 进度可见
06 尾款、发运与跟踪     → 运单号
```

**⚠️ 第 04 步是必须保留的核心**（见 §2.3）。
**但我们不写 20-30 天** —— 除非丰怀确认。

### ⑧ 可追溯点（T6 证据段）

**竞品三个**：工程评审 / CNC 进度 / 成品检查。

**我们照抄格式，但内容用丰怀真实能提供的**。
**⚠️ 如果丰怀不能提供生产照片，这段必须去掉 —— 不能承诺做不到的事。**

### ⑨ 定位承诺

**竞品**：*"You stay the seller. 2N stays behind you."*
> 不是推荐计划，客户还是你的客户。你控制本地报价、定价、服务和关系。

**★ 这是我们能直接用的 —— 而且要保持原文精神。**

**⚠️ 但必须写清边界**：我们会做到什么、不会做什么（不直接联系你的客户）。

### ⑩ 路由（T7 段型）

**三个出口**（合并竞品的第 5/10/11 段）：

```
贴牌（Private Label）    什么时候该把你的名字印上去
定制开发（Custom Dev）   OEM / ODM / 按图纸
轮毂目录（Catalog）      1018 个型号直接看
```

### ⑪ FAQ（8–10 条）

**竞品 7 条**，全部可借结构：

| 竞品问题 | 我们能答吗 |
|---|---|
| 能不能不囤货当经销商？ | ✅ |
| 有会员费吗？ | ⚠️ 待确认 |
| 有年度最低量吗？ | ⚠️ 待确认 |
| 有经销商价吗？ | ✅（按项目报） |
| 能从小批量开始吗？ | ⚠️ 待确认起订量 |
| 一个订单能混尺寸/前后配吗？ | ✅ **能**（3485 variant 支持） |
| 该先向客户收集什么？ | ✅ |

**★ 第 7 条「该先向客户收集什么」= 直接把销售话术给了经销商。**
**这是全页最实用的 FAQ**，我们照学。

**⚠️ 并吸收竞品第 5 段的物流内容**：
- 单套发运成本高
- 多单可合并（时机与路线对得上时）
- 物流时间 ≠ 生产时间

### ⑫ 收束 CTA（≤80 字）

**竞品 61 字**：*"YOUR SHELVES STAY LIGHTER. YOUR ORDER BOOK DOESN'T HAVE TO GET SHORTER."*

**⚠️ 必须 ≤80 字**（见 `content-design-and-new-pages.md` §1.1 规律二）。
**结尾不要再来一大段。**
