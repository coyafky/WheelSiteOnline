# GITHUB_FULL 参考

- Issue 是任务级事实；本地 `work/` 是中文规格、证据和档案。
- Milestone 是阶段聚合；Project 是跨阶段看板；Delivery Batch 是批次 PR 的集成边界。
- 每个现行本地任务与 Issue 双向链接；历史 completed/archive 不补造资源。
- 创建前只读核对仓库、默认分支、权限和现有资源；禁止重复、删除、关闭或重写已有资源。
- Project scope、字段、自动关联、worktree 和 PR 关联没有实测证据时标 WARN。
- 当前项目默认 GITHUB_FULL；权限不足时只能记录降级，不静默把项目规则改成本地模式。
