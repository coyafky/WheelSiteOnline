# 本地适配说明

以下偏离上游均为有意决定，更新时必须保留：

1. **中文不变**：所有项目规格、Issue、决策、状态和复盘记录使用中文。
2. **任务系统不变**：上游的 GitHub/GitLab/`.scratch` tracker 映射为本项目
   `work/queued → work/active → work/completed`。
3. **文档路由不变**：页面规格进入 `PAGE-SPECS/`，系统形状进入
   `ARCHITECTURE.md`，架构决定进入 `docs/adr/`，流程决定进入 `DECISIONS.md`。
4. **禁止自动提交**：上游 `implement` 的“完成后 commit”被移除；仍需用户明确授权。
5. **不强制并行 agent**：双轴评审默认可由当前 agent 顺序执行；只有用户明确要求
   sub-agent 或并行评审时才并行。
6. **接缝确认按风险触发**：已有架构指定的公共接缝直接使用；只有接缝选择会改变公共
   契约或显著成本时才询问用户。
7. **项目门禁追加**：CodeGraph、当前 Next.js 文档、内容接缝、发布门槛、Playwright、
   Docker 询盘验收及 session 收尾清单均高于通用默认值。
8. **不全量引入**：没有纳入 `triage`、`wayfinder`、`implement-spec` 等依赖外部 tracker、
   多分支或并行 agent 的流程，避免在现阶段引入第二套治理系统。
