## 1. WheelPros 实测：它怎么切轮毂

### 1.1 它的 URL 结构（两种）

```
/wheels                     全站目录（665 个轮毂，分 5 页）
/wheels/<brand>             按品牌：/wheels/rotiform、/wheels/tsw、/wheels/fuel-offroad…

/vehicle-gallery            车辆画廊（按品牌）
/vehicle-gallery/<brand>    按品牌：/vehicle-gallery/rotiform…
/vehicle-gallery?wheel_name=24163     按具体轮毂
/vehicle-gallery?gallery_diameter=7648 按直径
```

**★ 关键观察：它把「轮毂」和「车」分成两条线。**

| 线 | 路由 | 回答 |
|---|---|---|
| **产品线** | `/wheels/<brand>` | 「你们有什么轮毂」 |
| **车辆线** | `/vehicle-gallery/<brand>` | 「装上是什么样」 |

**但它的「车辆线」是按轮毂品牌切的，不是按车系切的。**
（`/vehicle-gallery/american-racing` 是**装了 American Racing 轮毂的车**）

→ ⚠️ **这点跟我们想做的不同**：我们要的是 `/tank-300-wheels`（**按车系找轮毂**），
比 WheelPros 的 `vehicle-gallery` 更贴近采购方的真实搜索意图。

### 1.2 ★ 它的完整筛选器（12 组）

实测 `/wheels` 页侧栏：

| # | 筛选项 | 原文 | 我们的数据支持 |
|---|---|---|---|
| 1 | **Fitment** | `Fitment` | ❌ 无（`suitableVehicles` 全空） |
| 2 | **Brand** | `Brand` | ⚠️ 我们没品牌（自有） |
| 3 | **New** | `New` | ⚠️ 可加（新品标记） |
| 4 | Feature Set | `Feature Set` | ⚠️ 可选 |
| 5 | **Finish** | `Finish` | ✅ **1349/1349** |
| 6 | **Diameter** | `Diameter` | ✅ **1349/1349** |
| 7 | **Width** | `Width` | ✅ **1349/1349**（在 `sizes` 里） |
| 8 | **Bolt Pattern** | `Bolt Pattern` | ✅ **1349/1349**（= PCD） |
| 9 | **Offset** | `Offset` | ✅ **1349/1349** |
| 10 | **Size** | `Size` | ✅ 同上 |
| 11 | **Lug Count** | `Lug Count` | ✅ 可从 PCD 派生（`5*114.3` → 5 孔） |
| 12 | **Material** | `Material` | ⚠️ 我们有 `process`（旋压/低压/锻造），**口径不同** |

### 1.3 它的产品卡片信息（值得学）

每个卡片只有 **4 行**：

```
[图片]
BLACK RHINO ARX              ← 品牌 + 型号
Sizes: 17"                   ← 尺寸
Material: Cast Aluminum      ← 材料/工艺
Features: Rock Guard         ← 特性（可空）
```

**极简。** 不堆参数 —— 详细规格留给单品页。

**★ 注意它的卡片标题是「品牌 + 型号」**（`ROTIFORM TDX`），
因为它是**多品牌经销商**。**我们是自有品牌，标题直接用型号 + 设计名即可。**

## 2. ★ 我们该怎么切（结论）

### 2.1 WheelPros 的切法 vs 我们的（关键差异）

| | WheelPros | 丰怀 | 为什么不同 |
|---|---|---|---|
| 主体 | **多品牌经销商**（25+ 轮毂品牌） | **自有品牌制造商** | 它按 Brand 切是必然，我们不需要 |
| 产品线 | 单线（轮毂） | **四条平行线** | 我们多一条线级 |
| 车辆线 | `vehicle-gallery`（**按轮毂品牌**） | `/fitment/<车系>`（**按车系**） | 采购方搜"坦克300轮毂"而不是"装了X牌的车" |
| 筛选器 | **12 组** | **建议 7 组** | 我们没有 Fitment/Brand 数据 |
| 询盘 | 加入购物车（零售） | **询盘**（B2B） | DEC-003 |

### 2.2 ★ 我们的筛选器（7 组，全部有数据支撑）

按**用户点选的优先级**排序 —— 最常用的放前面：

| 序 | 筛选项 | 数据字段 | 覆盖 | 备注 |
|---|---|---|---|---|
| 1 | **尺寸（直径）** | `sizeCategory` / `sizes` | **100%** | ⚠️ 须先归一化（见 §2.3） |
| 2 | **PCD / 孔距** | `pcds` | **100%** | ★ 采购方最高频的搜索词 |
| 3 | **孔数** | 派生自 `pcds` | **100%** | ⚠️ 派生时有脏数据，见下方 |
| 4 | **工艺** | `process` | ⚠️ **38%**（512/1349） | ★ 你必须要求的那三项 |
| 5 | **偏距 ET** | `offsets` | **100%** | 范围滑杆 |
| 6 | **中心孔 CB** | `centerBores` | **100%** | ⚠️ 多数用户不知道，放后面 |
| 7 | **表面处理** | `finishes` | **100%** | **679 个去重值**，须先分 4 组 —— 见 `wheel-catalog-page.md` §3.4 |

**❌ 明确不做的筛选项**：
- **Fitment（车型适配）** —— `suitableVehicles` 全空，**做了就是骗人**
- **Brand** —— 我们自有品牌，无此维度
- **Material** —— 与 `process` 重复，且我们的口径是工艺不是材料

#### ⚠️ 孔数派生时抓到一处脏数据

按 `pcd` 首段取孔数，实测结果：

| 孔数 | 型号数 |
|---|---|
| 5孔 | **1519** |
| 6孔 | 208 |
| 4孔 | 200 |
| 8孔 | 91 |
| 10孔 | 80 |
| **120孔** | **2** ← ❌ **脏数据** |

**`120孔` 是错的** —— 来源应是 PCD 写成 `10*120` 之类被误解析，
或存在 `120*...` 的畸形值。

**派生规则必须加白名单**，只认 `4 / 5 / 6 / 8 / 10`：

```js
const LUG_WHITELIST = new Set(["4", "5", "6", "8", "10"]);
const deriveLug = (pcd) => {
  const n = String(pcd).split("*")[0].trim();
  return LUG_WHITELIST.has(n) ? n : null;   // 非白名单 → null，不猜
};
```

**→ 这 2 个型号进「未标注孔数」分组，不静默归到任何一档。**
（与 §2.4 工艺的处理同源：**数据缺失要显式暴露，不能静默吞掉**）

### 2.3 ⚠️ 尺寸维度的归一化（必须做，否则筛选器是错的）

实测 `sizeCategory` 混着**源分册名**：

```
真实尺寸：15寸 16寸 17寸 18寸 19寸 20寸
脏值：    17寸-2 17寸-3 17寸-4 17寸-5
         18寸-2 18寸-3 18寸-4
         19寸-2 20寸-2
款式：    HP  越野款
```

**归一化规则**：

```js
// 17寸-3 → 17寸（剥离分册后缀）
const normSize = (s) =>
  s.replace(/-\d+$/, "")          // 17寸-3 → 17寸
   .replace(/^HP.*$/, "HP")        // HP轮毂 → HP
   .replace(/^越野.*$/, "越野款");  // 越野款保持
```

→ **产出两套独立维度**：
- **直径**：`15 / 16 / 17 / 18 / 19 / 20`（数值，可排序）
- **款式**：`HP` / `越野款`（**不是尺寸**，单列一组筛选项）

**✅ 规则已实测验证**（归一化后分布）：

| 尺寸 | 型号数 |
|---|---|
| 18寸 | **437** |
| 19寸 | 346 |
| 17寸 | 242 |
| 15寸 | 106 |
| 20寸 | 86 |
| 16寸 | 75 |
| 越野款 | 42 |
| HP | 15 |

**合计 1349 ✅**（与原数一致，归一化无损）

### 2.4 ★ 你点名的三个工艺（数据现状要说清）

用户原话：「PCD 工艺（旋压 低压 锻造）」

实测 `process` 分布：

```
旋压          350
低压          142
低压+旋压      20
───────────────
已标注         512  (38%)
未标注         837  (62%)
```

**⚠️ 三条纪律**：

1. **工艺是有效筛选项**（512 个有标注）—— 但不是全集
2. **选中某个工艺时，837 个未标注的不能静默消失**
   → 必须显示：「旋压（350）｜另有 **837 个型号未标注工艺**」
3. **未标注 ≠ 没有该工艺** —— 只是数据缺。**不得推测填充**（§`tech-architecture` 清洗纪律）

**建议**：把「未标注」做成一个**可勾选的显式分组**，默认包含。

## 3. ★ 车系专题适配页（你要求的）

### 3.1 与 WheelPros 的差异（这是我们的优势）

| | WheelPros | 丰怀 |
|---|---|---|
| 路由 | `/vehicle-gallery/<轮毂品牌>` | `/fitment/<车系>` |
| 意图 | 「看我这个牌子装上什么样」 | 「**我的车该买什么轮毂**」 |
| 匹配 | 图片匹配 | **PCD + 尺寸 + 孔数匹配** |

**★ 我们的做法更贴近真实采购意图。** 采购方的心智是：

> 「我卖坦克300 的轮毂，你们有哪些能装的？」

### 3.2 可建的车系页（实测型号数）

| 车系 | 型号数 | 路由 | 优先级 |
|---|---|---|---|
| **坦克**（300/400/500/700） | **77** | `/fitment/tank` | **P1** |
| **BJ40**（北京越野） | 40 | `/fitment/bj40` | **P1** |
| 奥迪 | 34 | `/fitment/audi` | P2 |
| 丰田 | 33 | `/fitment/toyota` | P2 |
| 奔驰 | 30 | `/fitment/benz` | P2 |
| 宝马 | 28 | `/fitment/bmw` | P2 |
| 牧马人 | 11 | `/fitment/wrangler` | **P1**（越野属性强） |
| 福特（猛禽） | 7 | `/fitment/ford` | P3 |
| 方程豹 | 6 | `/fitment/fangchengbao` | P3 |

**建议起步 3 个：坦克 / BJ40 / 牧马人** —— 都是越野，数据够，与丰怀越野款产线契合。

### 3.3 ★ 车系页的匹配逻辑（关键：分两层，不混淆）

**第一层：目录标注（可以直接上）**

数据源 = `styleName` 里提到该车系。

```
「这些型号的目录标注里提到了坦克」
```

**第二层：规格适配（需工程确认，暂不上）**

```
「坦克300 的 PCD 是 6*139.7，所以这些型号能装」
```

**⚠️ 两层的差别是根本性的：**

| | 第一层 | 第二层 |
|---|---|---|
| 依据 | 目录里的文字标注 | 车辆真实规格 |
| 声称 | 「车型参考」 | 「确认适配」 |
| 能不能上 | ✅ 能，**标注来源** | ❌ 需工程签字（DEC-004） |

**页面上必须写明**：

> 本页型号基于产品目录的车型标注整理，**非确认适配**。
> 具体安装请以下单前工程确认为准。

### 3.4 ★ 车系页可以「顺便」给出 PCD 参考（但标注来源）

实测我们能从数据反推：
- 坦克系型号出现在哪些 PCD 下 → `6*139.7`（193 个）占比最高
- BJ40 同理

**⚠️ 这仍然是「目录标注的统计」，不是「车辆出厂规格」。**
若要在页面上写「坦克300 常见 PCD：6\*139.7」，
**必须标注为「本目录该车系型号的 PCD 分布」而非「该车规格」** —— 否则是发布未确认数据。

### 3.4.1 ★ 实测：坦克 77 个型号的 PCD 是 **100% `6*139.7`**

```
坦克系型号: 77
PCD 分布:   6*139.7 → 77  （唯一值，无例外）
```

**这是个极干净的信号** —— 说明这批型号的数据来源一致、标注规范。

**但⚠️ 仍然只是「目录标注统计」，不是「坦克300 的出厂规格」。**
页面上若要显示，必须写成：

> 本页 77 个型号的目录标注 PCD 均为 `6×139.7`

**而不是**

> 坦克300 的 PCD 是 6×139.7 ← ❌ 这是发布车辆规格，需来源证明

### 3.5 车系页结构（八段式，承接 `fitment-pages-plan.md`）

```
/fitment/tank
  ① 车系 hero
  ② 快捷路径（坦克300 / 坦克400 / 坦克500 / 坦克700 分区）
  ③ 该车系的型号列表 ← 来自 styleName
  ④ 该车系的 PCD / 尺寸分布 ← 标注为「目录统计」
  ⑤ 推荐设计方向
  ⑥ 安装注意（★ 只写通用提示，不写具体 ET）
  ⑦ 路由（T7：三条出口）
  ⑧ FAQ + 询盘 CTA（携带车系上下文）
```

**★ 询盘要带上车系上下文** —— 客户从坦克页进来，询盘自动带上
「关注车系：坦克」「来源页：/fitment/tank」，销售一眼知道他要什么。

## 4. ★ 交叉方案：三个维度的专题页族

你提的「尺寸 / PCD / 工艺」+「车系」，合起来是**四个可自由组合的切法**：

```
                    ┌─────────────────┐
                    │  1,018 个型号   │
                    └────────┬────────┘
          ┌──────────┬───────┼───────┬──────────┐
          ↓          ↓       ↓       ↓          ↓
      按尺寸      按 PCD   按工艺   按孔数    按车系
      15–20寸    5*114.3  旋压…     5孔      坦克300
       100%       100%     38%     100%      57%(styleName)
```

| 切法 | 路由 | 覆盖 | 优先级 | 理由 |
|---|---|---|---|---|
| **PCD** | `/wheels/pcd/5x114-3` | **100%** | **P1** | 搜索意图最明确、数据最全 |
| **尺寸** | `/wheels/size/19` | **100%** | **P1** | 同上 |
| **车系** | `/fitment/tank` | 57% | **P1** | 直觉最强、转化最高 |
| 工艺 | `/wheels/process/flow-formed` | 38% | P2 | 须处理「未标注」 |
| 孔数 | `/wheels/lug/5` | 100% | P2 | 可并入 PCD 筛选 |
| 表面处理 | `/wheels/finish/gloss-black` | 100% | P3 | 已有 `/gallery/finishes` |

**★ 全部共用同一套模板**（竞品 M1「一个系统服务多页」的延伸）。

**URL 建议**：把 `PCD` 和 `尺寸` 放 `/wheels/` 下（属产品维度），
`车系` 放 `/fitment/` 下（属应用维度）。**两条线语义不同，不混。**

**关键差异一句话**：WheelPros 是**多品牌零售经销商**（按 Brand 切、Fitment 筛选、加购物车）；
丰怀是**自有品牌 B2B 制造商**（无 Brand 维度、按车系建专题、走询盘）。
**结构可借鉴，切法必须按我们的业务重定。**
