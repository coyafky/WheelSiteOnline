## 3. ★ 关键区分：styleName 里混着两种东西

扫描时发现 `styleName` 不是「车型」字段，它混了三类内容。**必须先分类才能用**：

| 类型 | 例子 | 能做什么 | 风险 |
|---|---|---|---|
| **A 车型名** | `坦克300` `BJ40` `牧马人` `方程豹` | ✅ **做适配页** | 低 |
| **B 品牌/竞品款号** | `TE37` `BBS-LM` `HRE-FF10` `Work-S1` `Rays-G025` | ❌ **不能做适配页**（是轮毂型号不是车） | ⚠️ **商标风险** |
| **C 形状/俗称** | `螳螂刀锋` `305树杈` `罗盘五星` `大王皇冠五辐` | ⚠️ 可做「设计风格」页 | 低 |

### 3.1 ⚠️ B 类是竞品商标（红线）

实测频次最高的 `TE37`（39 个）、`BBS-LM`（14）、`HRE-FF10`（19）、
`Rays-G025`（10）—— **这些全是别人的商标**：

| 名称 | 实际归属 |
|---|---|
| `TE37` / `Rays-*` / `ZE40` / `CE28` | **Rays（日本）** |
| `BBS-LM` / `BBS-RZD` / `BBS-CIR` / `BBS-FIR` / `BBS-RID` | **BBS** |
| `HRE-FF10` / `HRE-P103` / `HRE-P104SC` / `HRE-FF21` | **HRE** |
| `Work-S1` / `Work-ZR10` / `Work-VS-XV` | **Work（日本）** |
| `Vossen` / `ENKEI-PF01` / `TC4` / `T7R` | 各自品牌 |

→ **这些绝不能作为丰怀的产品名对外发布**（DEC-010）。
**可作为「风格参考」内部使用，但页面上必须改写成丰怀自己的命名**，
或用「类似 X 风格」的表述并规避商标风险。**必须先过法务。**

## 6. ★ 数据从哪来（这是本方案的关键）

我们**没有** `suitableVehicles` 字段。所以适配数据必须**从 `styleName` 派生**。

### 6.1 派生流程

```
assets/wheel-data/WHEEL-CATALOG-ALL.json
      ↓  提取 models[].styleName
      ↓  分类：A 车型 / B 品牌款号 / C 形状
      ↓  只保留 A 类 → 归一化（坦克 → 坦克300/400/500/700）
      ↓  建立 车型 → 型号列表 映射
src/content/fitment-by-model.ts     ← 生成物
      ↓
/products/wheels/fitment/[vehicle]   ← 1018 之外新增的适配页
```

### 6.2 ⚠️ 三条数据纪律

1. **只用车系名，不发布 ET/PCD/CB 作为「该车适配规格」**
   —— 我们有的是「这个型号的 styleName 提到了坦克」，
   **不是「这个型号适配坦克 300 且 ET 是 +35」**。
   后者需要工程确认（DEC-004）。**两者差别巨大，不得混淆。**

2. **页面必须标注数据来源与免责**
   —— 写「基于产品目录标注的车型参考」，**不写「确认适配」**。

3. **复合条目要拆开**
   —— `长城炮/坦克/北京212`（11 型号）必须拆成三条线，
   否则会在这三个页面各显示一次，看起来像重复。

### 6.3 可建的页面（按数据厚度排序）

| 车系页 | 型号数 | 优先级 |
|---|---|---|
| `/fitment/tank`（坦克总页，含 300/400/500/700 分区） | **77** | **P1** |
| `/fitment/bj40`（北京 BJ40） | 40 | **P1** |
| `/fitment/audi` | 34 | P2 |
| `/fitment/toyota` | 33 | P2 |
| `/fitment/benz`（奔驰） | 30 | P2 |
| `/fitment/bmw` | 28 | P2 |
| `/fitment/wrangler`（牧马人） | 11 | P2 |
| `/fitment/ford`（福特/猛禽） | 7 | P3 |
| `/fitment/fangchengbao`（方程豹） | 6 | P3 |
| 坦克 300 独立页 | 25 | P1（若坦克总页太挤就拆） |

**建议起步做 3 个：坦克 / BJ40 / 牧马人** —— 数据够、越野属性强、
车主改装需求明确、与丰怀的越野款产品线天然契合。

## 7. ★ 这个逻辑可以推广 —— 这才是真正的价值

你说「坦克的适配也是一样的，等等这个逻辑是也可以实现」——
**对，而且可以推广到一整族页面。**

### 7.1 三条可复用的「专题页」生成逻辑

| 逻辑 | 数据来源 | 能生成什么 |
|---|---|---|
| **按车系** | `styleName` 里的 A 类 | 坦克/ BJ40 / 牧马人 / 奔驰… |
| **按尺寸** | `sizeCategory` + `sizes` | `15寸轮毂` / `19寸轮毂` / `越野款` |
| **按 PCD** | `pcds` | `5x114.3` / `5x112` / `6x139.7`… |
| **按工艺** | `process` | `旋压轮毂` / `低压铸造` / `锻造` |
| **按表面处理** | `finishes` | `高亮黑` / `哑黑` / `古铜`… |

**这五种都是「同一批数据的另一种切法」，共用一套模板。** 这正是竞品 M1
（一个系统服务多页）的延伸。

### 7.2 ★ PCD 专页尤其值得做（SEO 价值最高）

实测 PCD 分布：`5*114.3`（662）｜`5*112`（439）｜`6*139.7`（193）｜
`4*100`（177）｜`5*120`（144）｜`5*108`（127）｜`5*100`（81）

**「5x114.3 轮毂」是采购方的真实搜索词** —— 用户不知道买什么型号，
但知道自己车的 PCD。而且 **PCD 覆盖率 100%（1349/1349）**，
不像 `styleName` 只有 762。**这是全站最扎实的专题页类型。**

### 7.3 优先级建议

```
1. PCD 专页       ← 覆盖 100%，搜索意图明确，先做
2. 尺寸专页       ← 覆盖 100%，搜索意图明确
3. 车系适配页     ← 覆盖 762（styleName），直觉最强、转化最高
4. 工艺专页       ← 覆盖 512（process），可做但须显示「未标注」分组
5. 表面处理页     ← 已有 /gallery/finishes，扩展即可
```

**前两项数据完整度 100%，不受 styleName 缺失影响，风险最低。**
