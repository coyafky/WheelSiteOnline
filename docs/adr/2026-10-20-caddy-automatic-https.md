# 新加坡单机入口采用 Caddy 自动管理 HTTPS

- 日期：2026-10-20
- 状态：已采纳

## 背景

腾讯云轻量应用服务器控制台提示当前实例镜像不支持一键设置 HTTPS。
根域名与 `www` 已解析到服务器；WordPress 需要独立的
`cms.fenghuaitech.store` 地址供后台、API 和媒体使用。用户要求在服务器侧
自动签发与续期证书。

## 决定

单机公网入口使用官方 Caddy 容器及持久化证书卷。DNS 指向本机且外部可达
80/443 后，由 Caddy 自动签发和续期证书。Next.js、WordPress、MySQL
仍只在回环或 Docker 私有网络提供服务。

发布资格未通过前，Caddy 只提供不含产品内容的维护响应，不把前后端接入公网。
公开切流时另行审核域名路由、转发来源头、后台访问控制、请求体与询盘限流，
并取得发布授权。

## 理由与影响

- 无需依赖腾讯云对实例镜像的一键 HTTPS 支持，也无需人工续签证书。
- 证书数据卷属于恢复资料，备份与迁移不能当作普通缓存删除。
- Caddy 标准模块不提供本项目原计划的 Nginx `limit_req`；正式发布前需验证
  应用限流并决定是否增加边缘限流。
