# 公司角色与商业模式知识条目

更新：2026-10-16。用于 SEO 语义分析、Topic Map 和内容规划。公开表述仍须过项目现行证据与发布门槛。

## 一句话内部建模

**已确认事实（FACT）**：项目主体为深圳峰徊科技有限公司；网站服务海外 B2B 采购商及少量 B2C 客户，承担产品信息、选型、工程/商务需求接洽与询盘入口。公司正式英文名称仍待品牌负责人核准。

**研究推断（INFERENCE）**：可在分析模型中把网站视作“连接经核准供货资源与海外买家需求的商业和项目接口”。这描述网站功能，不表示峰徊是所有产品的制造工厂，也不能直接作为首页公开定位句。

## 受众与可研究的决策角色

- 海外经销商、分销商和轮毂渠道：可能要找可供型号、规格、合作方式、私牌条款；具体条款和产品线适用性要逐项确认。
- OEM、Tier 1、系统集成商采购/工程团队：可能核对产品类别、工程输入、质量文件和供货责任；本项目当前无证据支持泛化的 OEM 资质或认证。
- 产品/制造/质量工程师：可能评估图纸、接口、材料、工艺、检验和应用风险；只有项目文件支持的参数才能进入内容。
- 车队与个人买家：关注产品识别、应用条件和下一步咨询；不可推断站点有零售、安装、车辆适配或道路救援承诺。

角色是研究框架，不是已访谈客户画像。若需证明市场需求，要用实际客户访谈、Search Console 或可追溯市场数据补强。

## 商业词的证据门槛

| 搜索修饰词 | 买家可能在确认什么 | 对峰徊的使用规则 |
|---|---|---|
| supplier / vendor | 是否能供货、如何开始采购 | 需确认具体 SKU/项目和实际供应主体 |
| manufacturer / factory / in-house | 是否有制造现场、设备和直接控制权 | 需逐工艺、逐主体证明；图片只说明场景，不自动证明归属 |
| OEM / ODM | 是否能依买方设计生产、共同开发或承接 OEM 关系 | 需确认产品线、合同模式和公开资格；词面不能作承诺 |
| private label / dealer / wholesale | 是否接受贴牌、批发或渠道合作及适用条款 | 需逐线确认真实项目、产品、品牌使用权、条款与交付范围 |
| certified / IATF / ISO / JWL / VIA / TÜV | 证书持有人、范围、有效期和产品覆盖 | 当前资料不足时不作为页面目标承诺；证书词只进待核验证据清单 |
| price / MOQ / lead time | 采购预算、门槛与排期 | 由实际询盘评估；无确认数据时不生成数字和诱导型承诺 |

## SEO 研究允许回答什么

可以回答：买家使用了什么表达；SERP 主要呈现哪些页面类型；query 指向发现供应商、学习规格、评估方案或启动 RFQ 中的哪项任务；现有页面是否与该任务匹配；缺少什么事实或页面能力。

不能仅靠 SEO 回答：峰徊是否有制造资质、产品能否适配某车型、供货价格/MOQ/交期、质量认证、工厂所有权、客户案例、售后范围或某产品线的真实需求规模。
