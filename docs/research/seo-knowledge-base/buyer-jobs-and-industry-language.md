# 买家任务与行业语言

更新：2026-10-16。本文件是 Topic Map 的解释词典。角色和任务来自项目范围、页面规格和一次性 SERP 观察；除非标为客户证据，不代表已访谈或已统计的市场事实。

## B2B 采购的典型决策链

汽车零部件项目通常要从“确认零件/产品类别”逐步走到“验证供应来源、技术适配、质量与法规、商务条件，再发起 RFQ”。这是一种分析框架；不同产品线、地区和客户的阶段可能跳过、合并或重排。关键词只能显示买家当下提出的问题，不能完整还原公司采购流程。

| 决策任务 | query 常见信号 | 买家可能要完成的动作 | 需要的页面/证据 |
|---|---|---|---|
| 发现类别/供应方 | supplier, manufacturer, products, who makes | 判断要联系谁、该需求属于哪条产品线 | 清晰实体介绍、产品入口、主体和供应关系 |
| 理解问题/技术 | how, what, vs, explained, guide | 建立基础知识、区分技术方案 | 准确解释、术语边界、可追溯技术来源 |
| 定义需求 | specification, drawing, size, PCD, housing | 把需求转成可沟通的尺寸/图纸/接口/市场条件 | 真实字段、工程输入清单、限制说明 |
| 比较候选方案 | best, compare, alternative, compatible | 在产品/供应方式中缩小选择 | 适用条件、证据、差异和限制；不能虚构排行 |
| 验证风险 | certification, test, quality, fitment, leak | 验证法规、质量、适配、性能风险 | 对应主体、型号、方法、适用条件、有效文件 |
| 准备询价 | quote, RFQ, custom, from drawing | 提交项目资料并进入销售/工程沟通 | 真实表单、输入要求、隐私和文件流程 |
| 商务筛选 | MOQ, price, lead time, wholesale, private label | 评估经济性、供货条件和合作模式 | 仅能用业务核准条款与具体条件回答 |

## 显性搜索意图与隐性搜索意图

- **显性意图**：query 直接表达的任务/对象。例如 `wheel offset calculator` 的字面任务是计算或换算 offset；`custom aluminum parts from drawing supplier` 表达从图纸寻找定制铝件供应方。
- **隐性意图**：买家提出 query 的更深层决策需要。例如 offset 计算背后可能是判断轮毂位置/干涉风险；按图询价背后可能是确认供应商是否看懂图纸、能否保密并给出可制造性反馈。这是推断，必须说明 query 线索、行业依据和未知项。
- **SERP 目标意图**：当前搜索引擎用什么结果满足 query，例如工具、产品目录、品牌解释、批发计划、厂商名单或零售商品页。它是页面构成观察，不等于每位搜索者的真实心理。

不得把三者合并成一个模糊的“商业意图”。输出时分别写：显性任务、隐性任务假设、SERP 页面意图、证据和置信度。

## 关键词修饰词不等于意图标签

- `manufacturer` 不证明 query 一定是高意向 B2B，也不证明本站可自称 manufacturer。
- `price`/`cost` 通常显式要价格信息；隐性可能是比较预算或验证是否可负担。若无可公开价格，判断页面是否可诚实承接，不能编范围。
- `best` 可能寻找清单、评论或购买建议，不等于找某一制造商。
- `OEM` 在 wheels 领域可指原厂替换件，也可指 OEM 采购关系；必须看 SERP。
- `custom` 可能表示定制设计、配置、按图制造或零售定制，不能自动归为 B2B RFQ。
- `how to` 可能是 DIY/维修任务，未必适合产品供应页。
- `near me`、城市/州修饰词可能要求本地门店或服务半径；对海外供货站通常存在意图错配。
- `certified`, `tested`, `compatible` 直接带验证期待；没有匹配证据时应作为不承接/待验证，而非内容机会。

## 站点能力与搜索需求必须双向匹配

Topic Map 每个主题要同时回答：

1. 搜索者的显性任务是什么？隐性任务是什么、为什么这样推断？
2. 当前 SERP 上占主导的页面类型是什么、证据日期/市场/语言是什么？
3. 峰徊有何真实产品、页面、数据、表单或文件可以承接？
4. 需要哪些事实/业务能力/页面功能仍未具备？
5. sitemap 当前是否已有合适 URL？该 URL 是否已索引批准、内容语言正确、页面任务吻合？

若网站没有承接能力，正确结果可以是“不做页面”“先补产品证据/表单能力”“仅页面模块”“等新数据再复核”。

## 证据与置信度

建议对每一项结论分别评级：

- **高**：多项独立证据一致（例如多组 query/SERP、GSC 实际 query/page 数据、已核准业务事实），并明确适用范围。
- **中**：query、业务任务和当前 SERP 相符，但样本量/区域/日期有限，或隐性动机仍属推断。
- **低**：只由词面、单个结果、AI 扩词或通用行业知识推出。

置信度不是搜索量，也不代表转化率。一个小样本的高相关性可以是中等意图置信，但市场需求规模依然 `NOT_AVAILABLE`。
