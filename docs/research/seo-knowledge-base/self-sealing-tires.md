# 自密封轮胎产品与行业知识条目

更新：2026-10-16。本站英文产品主词采用 `self-sealing tires`；技术说明和适用边界以当前页面规格及逐型号文件为准。

## 产品实体

**已确认事实（FACT）**：网站承接自密封轮胎产品/供应项目咨询，并解释胎面密封层的基本机制与边界。页面提到的内部 8 mm 测试条件只适用于规格中明确识别且有测试记录的型号与条件；不能泛化到所有轮胎、穿刺位置、异物形状、速度或市场。

自密封是产品结构/密封层功能的描述，不等于轮胎永不漏气、所有穿刺均可自行修复，也不替代检查、维修和制造商建议。

## 买家任务与意图

- **找产品/供应方**：采购人员可能查询 supplier、manufacturer、private label 等；隐性需要是核实可供型号、尺寸、市场文件、实际责任主体和供应安排。
- **理解工作机制**：车主、媒体或采购希望知道密封材料如何覆盖胎面穿刺，以及效果限制。SERP 可出现解释文章、品牌产品页、视频、AI 摘要，需按页面类型区分。
- **比较技术路线**：`self-sealing vs run-flat` 可能在比较应急移动能力、结构、使用限制和成本；两者不是同义技术，比较结论需工程审核。
- **处理穿刺或维护问题**：`repair`, `how long can I drive`, `downsides` 可能表达安全与维修需求。产品供应页不能替代专业检查建议或具体胎款制造商说明。
- **评估法规/市场要求**：可能询问 DOT、ECE 或其他法规。需要目标市场、型号、持有人、有效期和适用范围对应的正式文件。

## 用词和主张边界

| 用词 | 处理方式 |
|---|---|
| `self-sealing tire(s)` | 当前美国英文主词；作为产品/技术类别使用，但性能细节依型号与记录 |
| `self-sealing tyres` | 英式拼写变体；仅在目标市场适配的内容中自然覆盖 |
| `self-healing tire(s)` | 不作为本站产品的同义主词；需证明具体技术/市场用法后再判断 |
| `run-flat` | 不等于自密封；独立技术和采购任务 |
| `puncture-proof`, `never-flat` | 绝对化承诺，禁止作为本站产品描述 |
| `tire sealant` | 可能是液体补胎剂、预置密封层或维修化学品；必须从 query 和 SERP 判断对象 |

## 可公开的证据要求

涉及穿刺直径、区域、密封材料、测试程序、轮胎状态/气压、验收结果、可继续行驶距离、速度/负载、维修或更换建议、质保和法规时，证据必须识别轮胎型号、测试方法、条件、结果、责任主体和适用市场。生产或实验室照片只证明场景存在，不证明结果。
