# 汽车轮毂产品与行业知识条目

更新：2026-10-16。覆盖本站轮毂目录、旋压轮毂和锻造定制项目。所有型号/规格以已批准的内容数据为准。

## 产品实体与边界

| 子主题 | 已确认事实（FACT） | 不能混淆的边界 |
|---|---|---|
| 轮毂目录 | 页面通过真实型号与真实变体承接浏览和询盘；公开需型号、供货、规格、图片图权与人工审批通过 | 内部候选数据不等于公开 SKU；不可把候选数量写成在售数量 |
| 旋压（flow forming） | 页面是工艺说明与经批准旋压型号浏览入口；来源工艺字段限定可进入集合的型号 | 旋压不等于整体锻造；不能仅凭外观或市场术语推导具体毛坯、材料或性能 |
| 低压铸造 + 旋压 | 仅当源记录明确包含两道工艺时才可用该组合标签 | 不把单独的旋压记录扩写成低压铸造 |
| 锻造定制 | `/products/wheels/forged` 是定制项目/工程评估页，不是已核准型号目录 | 画册示例不是可售 SKU、规格、车辆适配、客户案例或图权批准 |
| 规格 | 可讨论尺寸、宽度、PCD/bolt pattern、ET/offset、center bore、finish 等字段 | 车型 fitment、刹车间隙、载荷、目标市场适用性需工程核验，字段存在不等于适配结论 |

## 买家任务（可用于构造主题）

1. **找型号与可选规格**：经销商/采购浏览批准目录，比较实际型号和可用变体。显性表达常带尺寸、PCD、型号或 catalogue；隐性任务可能是缩短初筛时间、确认可询价配置。必须检查目录此刻公开的数据，不能使用离线旧数量。
2. **理解规格术语**：个人客户、安装/采购人员理解 offset、backspacing、PCD、center bore 等。隐性风险常是买错规格或干涉；教育内容须明确术语解释不等于对某车适配。
3. **比较制造路线**：搜索者理解 flow formed、cast、forged 差异。页面需先辨认其在比较定义、成本/性能、供应商还是产品；SERP 页面类型用于判别，不能直接借用竞品性能数字。
4. **启动定制锻造项目**：品牌、经销、改装或个人项目方需确认设计/工程输入、材料和工艺路线。隐性任务通常是降低项目风险并确定供应责任；无项目证据时只描述评估流程。
5. **评估渠道/私牌合作**：买家寻找 dealer、wholesale、private label 或 OEM。词形相似但采购任务不同；页面必须有真实项目与条款支持，不能把有 URL 当作业务已开放。

## 搜索语义与同义边界

- `wheel` 与 `rim` 在美国日常搜索中可能交替使用，但特定 query 的 SERP 可能分别偏整轮、轮辋或零售；以当前搜索结果为证。
- `flow formed`, `flow forming`, `rotary formed` 等相近术语不能无证据统一映射为本站产品标签。以具体页面规格的可批准词汇为准。
- `forged wheel` 可以是产品采购，也可以是定制项目、零售品牌、价格或性能教育；加入 `manufacturer/supplier/custom` 也不保证纯 B2B 意图。
- `OEM wheels` 常有原厂替换件、零售和二手意图混入；要从 SERP 页面角色和目标客户判断，不能只按缩写分类。
- `5x114.3 wheels` 等规格词表达导航/筛选意图，但不能承诺某车型适配。PCD 是规格维度，不是 fitment 签字。
- `self-healing`、run-flat、puncture-proof、never-flat 不是 `self-sealing` 的可互换承诺词；详见[自密封轮胎条目](self-sealing-tires.md)。

## 关键词到页面的映射原则

- catalogue、具体已批准型号、真实规格：轮毂目录/型号详情。
- flow forming 工艺词：旋压入口；不要与 forged 定制页抢相同任务。
- forged/custom：锻造定制项目页；需表达项目评估，不编造库存型号。
- offset/PCD 教育：计算器或经审核的唯一 guide URL；先处理同主题重复页面和 canonical。
- OEM/private label/dealer：只有实际商业计划、页面批准与承接能力核实后才确定页面 owner。
- 年款/车型/品牌 fitment：当前均属于高风险候选，只有工程验证数据和页面审批后才重新评估。

## 禁止由搜索词推出的主张

减重/强度百分比、最大载荷、固定合金牌号、热处理、X 光/疲劳测试频次、认证、压力机吨位、价格、MOQ、交期、现货、特定车型适配、刹车间隙、事故/性能保证、峰徊自有工厂。需要具体项目文件、责任主体、适用条件和业务审核。
