# 新能源三电铝制部件产品与行业知识条目

更新：2026-10-16。本站页面是项目评估入口，不是标准 SKU 或完整零件目录。

## 产品范围

**已确认事实（FACT）**：页面围绕三类壳体/组件类别组织：水冷电机壳、高压铸造电机壳、电控/逆变器壳体。内容来源包括项目画册和供应商资料。页面帮助海外 OEM、Tier 1、系统集成商采购或工程人员判断项目是否可进入工程评估，并了解应提供的输入。

**关系边界**：资料中的类别、图片或供应商表述不能自动归为峰徊自有制造、产线、工艺能力、客户履历或量产能力。发布需确认具体供应主体、类别、图权和可公开范围。

## 买家任务

- **类别发现**：确认需求属于 motor housing、controller/inverter housing 或其他产品线。隐性需要是找到正确责任接口，避免向整机逆变器供应商询错零件。
- **工程适配性初筛**：采购/工程可能关心冷却方式、安装接口、密封面、连接器/线束空间、尺寸包络和工作环境。这里是待问的问题，不代表本站已验证参数或能设计所有方案。
- **供应商资格筛选**：可能要核对实际工厂、材料、工艺、质量文件、测试和项目经验。每项都需可识别主体、范围、日期和文件；不得补写 ISO/IATF、客户或测试数字。
- **启动 RFQ/开发**：准备图纸/3D、年度或项目数量、目标市场、功能边界和验证要求。只有当前表单/业务流程确实支持的输入才写为可提交项。

## 查询词解释框架

`EV motor housing supplier/manufacturer` 多为供应商发现/采购筛选候选；也可能寻找整机、电机总成或技术解释。`inverter housing` 既可能指外壳/壳体零件，也可能因搜索结果将 query 拉向 traction inverter 整机、厂商榜单、电力电子原理或家用逆变器。必须看 SERP 的结果实体、页面类型、是否真有 housing 词和目标地区结果，不能按词面直接决定新页面。

工程词可能对应隐性采购标准：热管理、液密/气密、结构载荷、EMC/接地、耐腐蚀、可制造性、加工余量、检测和法规资料。它们只能作为澄清问题/研究方向；不是本站已经具备的功能或指标。

## 内容与页面 owner 规则

- 当前主责入口为 `/products/ev-components`。在具体产品、供应主体与证据清楚前，先用经审核的类别模块，不自动拆 motor/inverter 独立页面。
- 将 housing 与 inverter whole unit、motor assembly、power electronics design 区分。
- 对参数型 query 先检查业务资料是否覆盖参数及试验条件；资料缺失时，结论应为“目前无法承接参数承诺”，并给出需要补的证据，不要生成说明文章填空。
- 来图项目的转换需求可与 `/request-a-quote` 或 `/custom-development` 链接，但不能承诺未存在的文件上传、保密流程或报价时限。

## 禁止推断

铝合金牌号、HPDC/挤压/机加工能力归属、壁厚、公差、气密/水密值、冷却效率、重量、功率范围、产能、模具能力、认证、OEM/Tier 1 资质、量产客户、报价/MOQ/交期、峰徊自有 EV 铸造厂。
