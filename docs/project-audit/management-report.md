# 网站研发进度与商业化上线评估报告

管理层简版入口：[网站研发项目驾驶舱](https://app.notion.com/p/3fd8de6ee7d281b596c3c622dffa1fc9)。本报告保留技术依据与审计口径，驾驶舱只呈现成果、阻塞、审批、里程碑和增长计划。

## 执行摘要

丰怀独立站已经从静态展示推进到可运行的 Next.js + Headless WordPress 架构，具备产品目录、内容发布控制、多语言路由骨架、SEO 基础设施和可持久化询盘主链路。当前阶段更准确的说法是“代码与预发布能力建设中”，不是“已具备正式商业上线条件”。

本轮审计发现 33 个页面路由模板、68 个组件资产、16 个业务功能域、8 个 Next HTTP 方法处理器、6 个 WordPress 自定义 REST 路径和 3 张询盘专用表。数字来自当前代码文件与注册点，不把动态路由模板误算成真实内容实例。

主要质量结果：单测 144/144、typecheck、主题检查、契约检查、构建和生产依赖审计通过；lint 失败 10 项，定向 E2E 20 通过/2 失败。因此不应报告“全量测试通过”。

## 已实现的商业价值

- 产品与制造能力可被结构化展示，内容可以通过 WordPress 维护并受批准状态控制。
- 轮毂目录和详情支持采购前的信息查找与询盘上下文绑定。
- 询盘先持久化再发信，并使用数据库唯一幂等键和事务 outbox 降低重复与丢失风险。
- 英文主站与四语言路由骨架为后续市场扩展提供基础；非英文内容仍需逐页批准。
- fail-closed 的 SEO 配置降低错误域名或未批准内容被搜索引擎收录的概率。

## 当前最大障碍

1. 当前工作树质量门禁未全绿：lint 和两项 E2E 失败。
2. WordPress 管理面尚未 HTTPS，真实客户端 IP 信任链有绕过限流风险。
3. 正式 OpenNext 平台、域名、DNS、TLS、镜像发布和自动回滚尚未批准并验证。
4. 法律文案、产品事实、图权、规格与公开语言需要业务/法务明确批准。
5. 真实邮件收件、备份恢复、异地加密、uptime 和告警送达未形成证据闭环。

## 路线图

| 阶段 | 目标 | 验收门槛 |
|---|---|---|
| 1. 止血 | 修 lint、E2E、安全头信任链 | P0 清零，`npm run check` 全绿 |
| 2. 集成 | 询盘、邮件、CMS、i18n 与 SEO 预发布验证 | 关键正常/异常路径有运行证据 |
| 3. 上线准备 | 平台、域名、TLS、备份、监控、回滚 | 所有上线硬门槛完成 |
| 4. 生产发布 | 人工批准后小窗口发布 | 健康、询盘、SEO、回滚抽查通过 |
| 5. 增长 | SEO、多语言、GEO、分析 | 以真实曝光/询盘基线迭代 |

## 管理层决策摘要

- 现在不建议上线。
- 先批准生产平台试点、正式域名/TLS、邮件服务和法律/产品内容审核责任人。
- 下一里程碑：P0 清零 + 预发布完整询盘链路 + 正式域名 SEO 产物核验 + 恢复/告警演练。
- 本报告不提供未经供应商报价支持的预算数字；成本需由平台、邮件、域名/TLS 和外部审核方案确定后补充。

## 审计覆盖与局限

已覆盖路由、组件文件、关键业务流程、HTTP 接口、CMS/询盘模型、测试配置与安全可执行检查。未覆盖生产 WordPress 数据实例数量、真实客户数据、正式 DNS/TLS、真实收件箱、外部监控、生产备份恢复和完整人工业务验收。
