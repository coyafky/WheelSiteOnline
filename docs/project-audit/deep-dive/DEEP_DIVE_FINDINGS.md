## 待验证而不能当成已证实缺陷的事项

1. 当前服务器镜像 digest、真实 Caddy 转发头、开放端口、Cron、备份和告警配置；本轮 SSH 无法认证（E-24）。
2. CMS 草稿、待审、撤回、删除与各语言的实际编辑权限及前端失效时序；匿名预览被拒绝是正向证据，仍缺授权编辑和撤回演练（E-07/08）。
3. 邮件最终送达率、退信回调、销售接收与跟进记录；历史两次合成成功不涵盖失败路径（E-12/13）。
4. 外部分析/CRM/站长平台账号、真实流量、索引和转化；不能据代码缺席报“绝对没有”（E-23）。
5. 云资源账单、续费、人工工作量与 ROI；本轮不填估计金额或收益率。
