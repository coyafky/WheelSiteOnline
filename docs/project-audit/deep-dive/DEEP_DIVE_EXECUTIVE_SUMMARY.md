## 一、结论与最先处理的事

网站已通过 HTTPS 临时公开，主站、产品、CMS 和健康检查可访问；全站边缘 noindex、robots 禁爬和 sitemap 404 与当前“先展示、暂不收录”的授权策略相符。**正式商业发布、正式搜索开放、可靠询盘运营和灾难恢复尚未达到证据门槛。** 这不是“网站不能用”的判断，而是公开事实、法律文案、故障恢复和可追溯发布仍有未关闭问题。是否满足具体法律义务由法务判断。

优先级最高的四项：

1. **F-01 Outbox `sending` 可滞留**：源码确定存在进程中断后无领取路径、告警触发不覆盖的窗口；生产未做故障注入。先在隔离 WP/MySQL 用合成询盘验证并修复。
2. **F-02/03 公开内容资格**：五项政策仍为假设/待审核文本，三篇工程测试文章和多处 `PLACEHOLDER` 已在正式域名 200。逐项批准、改写或按 CMS 流程撤回。
3. **F-04 发布版本不可唯一追溯**：生产记录是 `961762efd277-dirty-r2`，不能从当前 Git 提交复现精确字节；需干净构建、镜像 digest 和回滚证据。
4. **F-06/07 恢复和通知闭环**：历史合成询盘入库并到达测试邮箱、DB/媒体隔离恢复已完成；异地备份、告警送达、失败恢复和销售接收仍待验收。

详见[`问题登记`](DEEP_DIVE_FINDINGS.md)、[`证据台账`](DEEP_DIVE_EVIDENCE_LEDGER.md)、[`发布门禁`](RELEASE_GATES.md)、[`实施建议`](IMPLEMENTATION_BACKLOG.md)与[`架构及流程`](ARCHITECTURE_AND_FLOW_GAPS.md)。
