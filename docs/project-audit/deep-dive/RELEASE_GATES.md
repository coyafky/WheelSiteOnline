# 正式商业发布与搜索开放门禁

日期：2026-10-21。门禁针对**正式商业发布**，不撤销用户已授权的临时展示。`通过` 必须同时有可复核证据和责任人签字；代码存在、单测通过或公开 200 不单独构成通过。`未通过` 表示现有证据已经显示条件不满足；`待验证` 表示证据尚缺。任何 P0 未关闭，或关键 P1 无批准的缓解与验证记录，都不能进入正式发布审批。解除 noindex、上线、改 DNS、发真实邮件、花钱等仍按项目规则单独取得授权。

## 当前阶段判定

1. **临时展示**：用户已授权，公网 HTTPS 与全站不收录策略已确认。页面仍有未经批准的公开文字，因此只能称“技术上可展示、商业事实与法律资格未闭环”；是否满足具体法律义务需法务判断。
2. **正式商业发布**：**不批准**。G-01/02/03/06/08/09 等未通过。
3. **正式开放搜索收录**：**不批准**。现有禁止抓取符合临时策略；开放前须先关闭内容与法律门禁，再执行 G-10 独立审批。
4. **询盘运营**：正常合成提交已证明“入库并被邮件系统接受”，但 F-01 及销售/告警闭环未验收，不能宣称可靠运营完成。

## 上线前最小检查顺序

1. 先撤回或审批公开事实、测试文章和政策；同时修复并隔离验证 F-01。
2. 完成备份/恢复、告警送达、版本追溯和回滚；补齐销售接收演练。
3. 在隔离环境跑内容撤回、询盘故障、代理边界与关键用户任务；定位并修复本轮复现的两项 E2E 失败，重跑相关套件。
4. 管理层审阅证据并批准正式商业发布；SEO 单独决定是否解除 noindex。发布操作本报告未执行。
